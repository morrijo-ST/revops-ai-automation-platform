# RevOps AI Automation Platform

A synthetic revenue-operations command center that scores inbound leads, routes follow-up tasks, monitors SLA risk, and generates next-best-action recommendations.

## Demonstrates
- lead scoring
- pipeline hygiene
- CRM task routing
- SLA monitoring
- next-best-action logic
- AI-assisted email / follow-up patterns
- revenue operations dashboarding

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
